# 应用宝版《抓大鹅》一键颠锅

这是一个面向 Windows 应用宝电脑版的非侵入式小工具。它不会修改、注入或读取游戏数据，只做一件事：触发应用宝提供的“摇一摇”，模拟手机快速上下摇晃，让《抓大鹅》里的物品翻动。

工具会优先尝试通过 ADB 向模拟器发送加速度变化；应用宝未开放该接口时，会自动点击应用宝顶部“工具箱”中的“摇一摇”。

## 使用

要求：

- Windows 10/11；
- 已安装应用宝电脑版和《抓大鹅》；
- 使用系统自带的 Windows PowerShell 5.1 或更高版本。

首次使用建议开启应用宝 ADB：

1. 打开应用宝“设置”；
2. 在设置界面连续点击“性能”7 次；
3. 勾选“开启开发者模式”并保存；
4. 启动《抓大鹅》，进入需要颠锅的关卡。

然后双击 [`一键颠锅.cmd`](./一键颠锅.cmd)。成功时窗口会直接关闭；失败时会保留错误信息和排查提示。

也可以在 PowerShell 中运行：

```powershell
.\run-goose.ps1
```

## 配置

默认配置在 [`config.json`](./config.json)：

| 配置 | 含义 |
| --- | --- |
| `mode` | `auto`：ADB 不可用时自动回退到应用宝界面；`adb`：只用 ADB；`ui`：只点击官方“摇一摇” |
| `adbPath` | `adb.exe` 的完整路径；留空会从 PATH、应用宝注册表和默认安装目录自动查找 |
| `serial` | 应用宝 ADB 地址，新版默认是 `127.0.0.1:5555` |
| `windowTitle` | 用来定位游戏窗口的标题，默认 `抓大鹅` |
| `cycles` | 单次进程的颠锅次数，ADB 与界面模式均生效；硬限制为 1–10，越界会在任何操作前报错退出 |
| `intervalMs` | ADB 加速度变化及 UIA 连续点击之间的间隔，范围 30–1000 毫秒 |

命令行参数可临时覆盖配置，例如：

```powershell
.\run-goose.ps1 -Mode ui
.\run-goose.ps1 -AdbPath "D:\Program Files\Tencent\Androws\Application\5.10.56.1\adb.exe"
.\run-goose.ps1 -Cycles 10 -IntervalMs 80
```

`cycles` 不会被静默截断。配置文件或命令行传入 0、11 等越界值时，程序会在连接 ADB 或操作应用宝窗口之前显示中文错误并退出。为避免 ADB 子进程卡死，单次运行还设有 30 秒总时间上限。

## 常见问题

- **找不到游戏窗口**：先启动应用宝并打开《抓大鹅》，不要最小化游戏窗口。
- **ADB 连接失败**：按上面的步骤开启开发者模式；应用宝引擎启动可能需要约 20 秒。
- **识别不到“工具箱”或“摇一摇”**：让应用宝顶部导航栏保持可见，确认当前版本支持“摇一摇”；也可直接在工具箱中手动验证该按钮。
- **游戏没有翻动**：确认游戏内没有开启“低耗能”，并允许设备动作与方向权限。
